# Release Channels

Status: `PUBLIC_RELEASE_CHANNEL_DEFINED_ENTERPRISE_CHANNEL_PLANNED`

## Community Release Channel

The Community/Core channel is public and Apache-2.0:

- public GitHub releases;
- Apache-2.0 source;
- public container image when published;
- public SBOM or dependency metadata when available;
- reproducible public artifacts;
- publication and brand validation.

## Enterprise Release Channel

The Enterprise channel is planned and blocked pending ownership and commercial-authority confirmation:

- private release repository or registry;
- authenticated distribution;
- enterprise SBOM;
- commercial release notes;
- signed or hardened builds only after implementation;
- separate support lifecycle only under approved support terms.

Do not claim a hardened enterprise release until there is an implemented build, test, vulnerability-management, and signing process supporting that claim.
