# RAG Compass Name Migration

`RAG Compass` is the forward-facing display name for the optimizer historically identified as `ragwarrant_no_fork`.

Machine-readable identifiers remain stable:

- `optimizer_id`: `ragwarrant_no_fork`
- `stable_internal_id`: `ragwarrant_no_fork`
- `canonical_display_name`: `RAG Compass`
- Legacy names: `No-Fork`, `RAGWarrant-No-Fork`, `ragwarrant_no_fork`, `ragwarrant_no_fork`

Historical artifacts are not rewritten. New human-readable reports should use `RAG Compass`; audit-sensitive contexts may use `RAG Compass (legacy id: ragwarrant_no_fork)`.
