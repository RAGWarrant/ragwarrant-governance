# Operational contract template

This template identifies owner-authoritative inputs required before any real
stratified confirmatory study. It does not freeze operational values and must
not be interpreted as execution authorization.

| Field | Required value |
|---|---|
| Target population | `OWNER_OR_DEPLOYER_INPUT_REQUIRED` |
| Sampling frame | `OWNER_OR_DEPLOYER_INPUT_REQUIRED` |
| Unit of observation and cluster/duplicate rule | `OWNER_OR_DEPLOYER_INPUT_REQUIRED` |
| Group codebook | `OWNER_OR_DEPLOYER_INPUT_REQUIRED` |
| Missing and ambiguous group handling | `OWNER_OR_DEPLOYER_INPUT_REQUIRED` |
| Recruitment channels | `OWNER_OR_DEPLOYER_INPUT_REQUIRED` |
| Recruitment time window | `OWNER_OR_DEPLOYER_INPUT_REQUIRED` |
| Exchangeability acceptance criteria | `OWNER_OR_DEPLOYER_INPUT_REQUIRED` |
| Privacy rules | `OWNER_OR_DEPLOYER_INPUT_REQUIRED` |
| Data-retention rules | `OWNER_OR_DEPLOYER_INPUT_REQUIRED` |
| Core and conditional inclusion probabilities | `OWNER_OR_DEPLOYER_INPUT_REQUIRED` |
| Group-screening cost | `OWNER_OR_DEPLOYER_INPUT_REQUIRED` |
| Full-evaluation cost | `OWNER_OR_DEPLOYER_INPUT_REQUIRED` |
| Recruitment and screening cap | `OWNER_OR_DEPLOYER_INPUT_REQUIRED` |
| Recruitment-failure behavior | `OWNER_OR_DEPLOYER_INPUT_REQUIRED` |

The research default remains fail closed. Missing fields, unmet quotas, or a
failed exchangeability review block execution. Placeholders above are neither
population definitions nor privacy commitments, and the synthetic planning
superpopulation is not a substitute for these owner inputs.
