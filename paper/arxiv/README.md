# RAGWarrant arXiv Source Package

This directory documents the arXiv-oriented source package for the RAGWarrant v0.1.0-rc1 preprint.

Primary files:

- `../main.tex` — manuscript source generated from `../preprints/RAGWarrant_ArXiv_Preprint_v0.1.1-rc1.docx`.
- `../refs.bib` — BibTeX references preserving the Word manuscript reference order.
- `../figures/` — vector figure PDFs plus source/data companions.
- `ABSTRACT.txt` — abstract text checked against arXiv's 1,920 character limit.
- `SUBMISSION_CHECKLIST.md` — human submission checklist.
- `source_manifest.txt` — source package file manifest.

Raw datasets, prompts, generated answers, CRAG source documents, API responses, secrets, and private paths are not included.
